# 히득키득 — 처음 실행하는 사람을 위한 한 장 안내

**대상:** 현재 노트북의 기존 프로젝트. **실행 방식:** 포장 없이 폴더에서 로컬 PC 점검. 관리자 권한은 필요 없습니다. 다른 PC에서는 실제 프로젝트·Node.js 위치가 다르므로 아래 경로를 그대로 쓰지 않습니다.

## 1. 준비하고 켜기

일반 Windows PowerShell을 열어 아래를 순서대로 실행합니다. 기존 폴더를 지우거나 옮기거나 압축을 다시 풀지 않습니다. 별도 npm 설치·포장 명령도 필요 없습니다.

```powershell
$nodeDir = "$env:USERPROFILE\Downloads\node-v24.19.0-win-x64\node-v24.19.0-win-x64"
$appDir = "$env:USERPROFILE\Desktop\Aleph 방어전 13단계 준비\on-client"
if (!(Test-Path -LiteralPath "$nodeDir\node.exe")) { throw 'Node.js 위치를 확인해 주세요. 이 단계에서 중단합니다.' }
if (!(Test-Path -LiteralPath "$appDir\tools\start-alekov.ps1")) { throw '기존 on-client 폴더 위치를 확인해 주세요. 이 단계에서 중단합니다.' }
$env:Path = "$nodeDir;$env:Path"
Set-Location -LiteralPath $appDir
node --version
```

`v24.19.0`과 `on-client` 폴더 위치를 확인한 뒤 실행합니다. 위 단계에서 오류가 나면 다음 명령으로 넘어가지 않습니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -NoNativeHost
```

‘케셰브가 켜졌습니다’가 나오면 브라우저에서 **http://127.0.0.1:5189/** 을 엽니다. 실행 도구의 ‘케셰브’는 기본 이름이며 앱 이름 설정은 ‘히득키득’입니다. 사용하는 동안 PowerShell 창을 유지합니다. Node 경로 추가는 이 PowerShell 창에만 적용됩니다.

## 2. 화면에서 확인하기

1. **보호 현황 → 내 PC 확인:** 위쪽 CPU·메모리·디스크 여유·방화벽 카드와 아래 네트워크·Windows 기록을 봅니다. 실측 시각은 KST, CPU는 %, 용량은 GiB입니다. Windows 경고·오류 건수는 침해·공격 탐지 판정이 아닙니다.
2. **내 PC 확인을 한 번 더:** 아래 추이·조회 기록과 이전 실측 대비 변화를 확인합니다. 기록은 현재 탭에서만 유지되며 새로고침하면 초기화됩니다.
3. **학생 상태·알림 표시 → 다시 조회 · 실측 비교 설명:** 첫 조회는 ‘이전 유효 실측 없음’, 두 번째 조회는 이전 성공 조회 시각과 변화량을 표시합니다. 이 버튼은 학생 설명만 갱신하므로 위쪽 PC 카드의 시각과 다를 수 있습니다. Tab으로 이동하고 Enter·Space로 누를 수 있습니다.
4. **SDP 상태 확인:** PC 조회와 별도의 상태입니다. 이번 로컬 실행에서 ‘SDP 미연결’이 나와도 PC 실측 실패는 아닙니다. 읽지 못했으면 ‘확인 불가’와 이유를 확인합니다. 예시 값으로 대신 표시하지 않습니다.

## 3. 막혔을 때와 종료

| 보이는 문구·상태 | 다음 행동 |
|---|---|
| `node`를 찾지 못함 / Node.js 위치 오류 | 1번의 실제 Node 폴더를 확인합니다. ZIP 압축 해제만으로 모든 PowerShell에 등록되지는 않습니다. |
| 앱 폴더를 찾지 못함 | `package.json`과 `tools/start-alekov.ps1`이 있는 기존 `on-client` 위치를 확인합니다. 새 프로젝트를 만들지 않습니다. |
| 포트 5189 사용 중 | 기존 앱인지 먼저 봅니다. 다른 프로그램은 종료하지 않습니다. 필요하면 실행 명령 끝에 `-Port 5190`을 붙이고 브라우저도 `http://127.0.0.1:5190/`으로 엽니다. |
| 페이지 연결 거부 / `NETWORK_ERROR` | PowerShell의 시작 안내와 포트 번호를 확인합니다. 앱을 켠 뒤 다시 조회합니다. |
| `ALEKOV_NATIVE_PREPARE_ACL_UNSAFE` | 계정 설정 권한 문제입니다. 위 로컬 명령의 `-NoNativeHost` 여부를 확인합니다. 설정·권한을 임의로 바꾸거나 지우지 않습니다. 이 옵션은 권한 오류를 복구하는 명령이 아닙니다. |
| 항목 ‘확인 불가’ | 항목의 이유를 읽고 다시 조회합니다. 권한 부족이면 관리자 권한으로 바꾸지 말고 담당자에게 확인합니다. |

**종료:** 앱을 켠 PowerShell에서 `Ctrl+C`. 다시 켤 때는 1번부터 따라 합니다. 이 안내의 실행은 계정·AI·SDP 실제 연결을 포함하지 않습니다. 앱 시작이나 PC 실측 성공을 그 연결 성공으로 기록하지 않습니다.

**따라 하기 기록:** 실행자 / 확인 시각 / 마지막 성공 단계 / 막힌 단계 / 오류 원문 / 안내 수정 후 재시도 결과를 남깁니다. 확인 번호·토큰·설정 파일 내용은 기록하지 않습니다. ‘막힘 없음’도 실제 실행한 뒤에만 적습니다.
